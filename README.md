# 神経衰弱
このPythonコードは、コンソール環境で動作する本格的な「神経衰弱（カード合わせゲーム）」のプログラムです。

プログラム全体は、ゲームの進行を制御するいくつかの関数と、それらを統括するメインの処理によって構成されています。最初に実行される難易度選択画面では、プレイヤーが「EASY」「NORMAL」「HARD」のいずれかを選択することができ、その選択に応じてカードの総数と盤面の列数が自動的に決定されます。難易度が確定すると、アルファベットのペアからなるカードがランダムにシャッフルされて生成され、ゲームがスタートします。

ゲームのプレイ中、盤面のカードは未選択のものが「？」として隠された状態で表示され、プレイヤーはプロンプトに従って1枚目と2枚目のカードの番号を順番に入力します。この入力受付の際には厳密なエラーチェック（バリデーション）が機能しており、数字以外の文字列が入力された場合や、盤面の範囲外の番号、すでに揃っているカード、あるいはすでに選択済みのカードを指定した場合には、適切な警告メッセージが表示されて再入力を促す仕組みになっています。

2枚のカードがめくられた後には絵柄の一致判定が行われ、同一のアルファベットであればペア成立として記録され、異なっている場合はミスとしてカウントされます。判定結果が表示された後は一定の待機時間を挟んで次のターンへと移行します。すべてのカードのペアが揃うとゲームクリアとなり、クリアまでのターン数、ミス回数、プレイ時間、および難易度に応じたボーナスや減点が反映された最終スコアが計算され、結果画面として出力されます。

ゲーム終了後には継続確認のプロンプトが表示され、プレイヤーが「y」を入力した場合は最初から再プレイが可能となり、「n」を入力した場合は終了メッセージとともにプログラムが安全に終了するように設計されています。
